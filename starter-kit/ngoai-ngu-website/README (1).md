# Website trung tâm ngoại ngữ

## Giới thiệu

Dự án xây dựng website **Trung tâm ngoại ngữ** nhằm hỗ trợ quản lý khóa học, học viên và đăng ký học. Website giúp việc quản lý thông tin trở nên ***nhanh chóng và thuận tiện***

## Cây thư mục

|Thư mục|Nội dung|
|-|-|
|docs|chứa thời khóa biểu|
|media|chứa hình ảnh và logo|
|data|chứa dữ liệu Excel|
|logs|chứa file log và báo cáo|

``` powershell
Get-Childltem -Recurse -Force
```

## Công việc cần làm

* \[ ] Hoàn thiện bảng học phí tháng 3
* \[ ] Kiểm tra dữ liệu đăng ký học
* \[x] Tạo cấu trúc thư mục dự án

> Lưu ý: Không upload file `.env` lên GitHub
